# Playwright Vendure Framework

A professional UI automation framework built with Playwright and TypeScript for the Vendure e-commerce platform.

This project is being developed as a real-world QA Automation portfolio project, following industry best practices including the Page Object Model (POM), reusable components, clean code principles, and scalable test architecture.

---

- Playwright
- TypeScript
- Node.js

## Getting Started

Clone the repository

```bash
git clone https://github.com/nimanthafernandoqa/playwright-vendure-framework.git
```

Install dependencies

```bash
npm install
```

Run all tests

```bash
npx playwright test
```

Run tests in headed mode

```bash
npx playwright test --headed
```
